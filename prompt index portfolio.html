03 / Core subject

Understanding Prompt Engineering

Prompt engineering is the practice of designing, testing, and improving instructions given to an AI system so its response is more relevant, clear, and useful.

A useful prompt includes

  • Role: the perspective or expertise requested.
  • Task: the exact work to be performed.
  • Context: relevant background information.
  • Constraints: tools, length, language, or limitations.
  • Output format: the structure expected.
  • Verification: checks for accuracy and usefulness.

My prompt design workflow

  1. Define the result I need.
  2. Add the context that matters.
  3. Choose a helpful role or perspective.
  4. Set clear requirements and constraints.
  5. Specify the output format.
  6. Review, refine, and verify the response.

Reusable prompt template

Prompt templateAct as [role]. Help me [specific task]. Context: [relevant background]. Requirements: [constraints and tools]. Present the result as [format]. Explain important assumptions and include a way to verify the result.
04 / Methods

Prompting techniques

Different techniques help communicate different kinds of tasks. The best choice depends on the problem and the context available.

01. Zero-shot prompting

Ask for a task directly without providing an example.

“Explain what a Python list is in simple language.”

02. Few-shot prompting

Provide a few examples to demonstrate the expected pattern.

“happy → positive; awful → negative. Now classify: useful.”

03. Role-based prompting

Ask the AI to respond from a relevant perspective.

“Act as a Python tutor and explain this error to a beginner.”

04. Stepwise prompting

Break a complex task into an ordered sequence of stages.

“Organize this debugging task into diagnosis, possible causes, fix, and tests.”

05. Contextual prompting

Supply project-specific background and constraints.

“For my college attendance app, explain how GPS validation could fit into the workflow.”

For complex questions, I can request a concise explanation of the main steps, assumptions, and checks. I focus on useful explanations and verifiable results.

06 / Practical work

Prompt experiments

Examples of reusable prompts for academic learning and project tasks.

Learning a concept

Goal: understand a technical topic at beginner level.

Act as a patient computer science tutor. Explain [topic] for a first-year B.Tech student. Include a simple definition, an everyday analogy, one technical example, and three revision points.

Debugging code

Goal: investigate an error instead of blindly replacing code.

Act as a programming mentor. Review the code and error message. Identify the likely cause, explain it simply, suggest the smallest correction, and provide tests for normal, boundary, and invalid inputs.

Website planning

Goal: turn a project idea into a structured website plan.

Act as a UX planner. For [project], identify target users, core problem, key pages, main user journey, accessibility needs, and a responsive layout.

Research support

Goal: separate established facts from assumptions.

Act as a research assistant. Outline a report on [topic]. Separate facts, assumptions, and questions requiring verification. Suggest credible source types and a checking list.

Presentation preparation

Goal: prepare concise content for a college presentation.

Act as a presentation coach. Turn these notes into a six-slide outline. For each slide, give a title, up to four points, and one suggested visual. Avoid unsupported claims.

08 / Quality checks

Evaluating AI responses

A polished response is not automatically correct. I use a checklist before relying on AI-generated content.

Relevance

Does the answer address the actual task?

Accuracy

Can factual claims and technical details be verified?

Completeness

Are requirements, edge cases, or limitations missing?

Clarity

Can I understand and explain the result myself?

Testability

Can code or instructions be tested with expected results?

Privacy & integrity

Is sensitive information protected and assistance used responsibly?
